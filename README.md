# travelling-thief-metaheuristics

Metaheurystyki (losowa, zachlanna, EA, SA/TS) dla Travelling Thief Problem (TTP1).
C++ (algorytmy) + Python (wykresy, tabele).

## Struktura
- include/ttp, src: kod C++
- data: instancje .ttp (easy/medium/hard/extra)
- configs: konfiguracje eksperymentow
- results: CSV z przebiegow
- scripts: analiza wynikow w Pythonie
- tests: mala instancja do recznej weryfikacji funkcji oceny
